SSH Key Setup Guide

1. Generate the SSH Key Pair
Run this command in your terminal:
ssh-keygen -t ed25519 -C "software.vbo@gmail.com.local" -f ./id_ed25519 -N ""
2. Copy the Public Key
Run this command to view it, copy it, and add it to your Git host (e.g. GitHub Repository Settings → Deploy Keys → Check "Allow Write Access"):
cat ./id_ed25519.pub
3. Copy the Private Key
Run this command to view it, copy the entire output (including the BEGIN/END lines), and paste it into the PEM key input on this page:
cat ./id_ed25519
4. Save & Test Connection

Ensure the Remote URL is in SSH format (e.g. git@github.com:username/repo.git) and click Test Connection below.
